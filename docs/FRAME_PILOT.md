# Frame artwork pilot

The Illinois and Boeing 2707 each have independently composed landscape and portrait illustrations. The built-in image generator produced the colour masters. They were resized to 2560 × 1440 or 1440 × 2560 pixels as sRGB JPEGs. The portrait composition of The Illinois was trimmed at the sides to reach 9:16 while retaining the whole tower. The artwork is an artistic reconstruction. The caption and development stage are rendered separately in Liquid.

The Boeing 2707 scenes interpret the late fixed-wing 2707-300 proposal. The exhibit’s surviving museum mock-up is from a different configuration. The tower scenes interpret Wright’s 1956 proposal, with the Chicago skyline used for a sense of scale. [NASA configuration reference](https://ntrs.nasa.gov/api/citations/19940021652/downloads/19940021652.pdf) · [Wright elevation archive](https://jgonwright.net/asp/FLLWchrono5.aspx?id=3888)

Automatic display selection uses TRMNL’s `screen--frame` class. The Frame option forces the gallery layout for previews. Classic forces the standard layout. All three compact layouts use the classic artwork and layout. Exhibits without new art use the landscape or standard grayscale image in the gallery layout. [TRMNL device profiles](https://trmnl.com/framework/docs/3.4/devices) · [TRMNL model registry](https://trmnl.com/api/models)

Run the existing catalogue, asset, Saved State and device checks before adding more exhibits. Compare the four compositions on a physical Spectra 6 panel before choosing a palette for the rest of the collection.
